# **Feelpath**
**ネットワーク可視化・分析Webアプリ**

このプロジェクトは、ブラウザ上でネットワーク（グラフ）を作成・編集・解析できるWebアプリです。ReactとNext.js（App Router）で実装されており、グラフの操作や統計解析を直感的に行えます。
  
**※注意**

- 本アプリはフロントエンド（Next.js）だけで動作します。バックエンドは不要です。
- グラフの保存・読み込みはlocalStorageを利用しているため、**同じ端末・同じブラウザ**でのみデータが保持されます。
- ブラウザのキャッシュクリアやシークレットモードではデータが消える場合があります。
  
**使い方**

![画面例](./picture/feelpath01.png)
  
1. **1. ノードの追加**  
   左メニューでノード名を入力してキャンバスをクリックすると、ノードを追加できます。
  
2. **2. エッジの作成**  
   ノードをクリックして、エッジを作成可能です。重みも設定できます。
  
3. **3. 始点・終点の設定,経路表示**  
   ノードを選択して、始点・終点を設定できます。
   「最短経路」「最長経路」ボタンを押すと、経路が表示されます。
  
![画面例](./picture/menu_grah01.png)
  
4. **4. 学習カードでの分析**  
   - 次数分析  
   - 行列表示  
   - 次数分布の確認

![画面例](./picture/menu_class.png)
  

5. **5. グラフの保存・読み込み**

   保存ボタンでグラフをlocalStorageに保存できます。

![画面例](./picture/menu_save.png)
  
   保存時に発行されるIDを使って、同じ端末・ブラウザであればいつでもグラフを読み込むことが可能です。

![画面例](./picture/menu_save02.png)
  
6. **6. メモ入力**  
   メモ欄で自由にメモを入力できます。

![画面例](./picture/menu_memo.png)
